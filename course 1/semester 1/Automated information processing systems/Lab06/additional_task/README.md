### Задание: Определение свойств целого числа

**Цель:** Написать программу на языке C++, которая определяет различные свойства введенного целого числа.

**Описание:**

1. Программа должна запрашивать у пользователя ввод целого числа \( x \) (кроме нуля).
2. Программа должна проверять корректность введенных данных:
   - Если введены неверные данные (например, дробное число или ноль), программа должна выводить сообщение об ошибке.
3. Программа должна определять и выводить следующие свойства числа:
   - Четное или нечетное.
   - Положительное или отрицательное.
   - Простое или составное.
4. Если число составное, программа должна выводить все его делители.

**Пример работы программы:**

```
Введите целое число (кроме нуля): 12
Чётное
Положительное
Составное
Все делители числа:
1
2
3
4
6
12
```

**Требования:**

- Использовать условные операторы `if` для определения свойств числа.
- Использовать цикл `for` для нахождения всех делителей числа.
