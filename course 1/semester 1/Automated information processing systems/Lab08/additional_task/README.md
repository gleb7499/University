### Задание: Обработка строки на языке C++

**Цель:** Написать программу на языке C++, которая обрабатывает введенную строку и выполняет определенные преобразования в зависимости от длины слов и наличия гласных букв.

**Описание:**

1. Программа должна запрашивать у пользователя ввод строки.
2. Программа должна определять длину каждого слова в строке.
3. Если длина слова четная, программа должна переворачивать это слово.
4. Если длина слова нечетная, программа должна заменять каждую гласную букву в слове на ее порядковый номер в алфавите.
5. Программа должна выводить преобразованную строку.

**Пример работы программы:**

```
Введите строку: привет мир
тевирп м10р
```

**Требования:**

- Использовать функции `cin.getline()` для ввода строки.
- Использовать массив `letters` для определения порядкового номера гласных букв.
- Использовать циклы `for` и условные операторы `if` для обработки строки.
- Обеспечить корректный ввод и вывод данных.
