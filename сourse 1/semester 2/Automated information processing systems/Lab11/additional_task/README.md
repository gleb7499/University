### Задание: Проверка корректности скобочной последовательности  

**Цель:** Написать программу на языке C++, которая проверяет правильность расстановки скобок в строке.  

**Описание:**  

1. Программа запрашивает у пользователя ввод строки, содержащей скобки ``()`` , ``[]`` и ``{}``.  
2. Проверяется корректность ввода:  
   - Строка не должна быть пустой.  
   - Строка должна содержать только допустимые символы (скобки, пробелы, табуляции).  
3. Программа анализирует баланс скобок и их корректное закрытие.  
4. Выводится результат проверки:  
   - `"Строка правдива"` – если последовательность корректна.  
   - `"Строка ложна"` – если имеются ошибки в расстановке скобок.  

**Пример работы программы:**  

```
Введите строку: { [ ( ) ] } 
```  
``` 
Строка правдива 
```  

``` 
Введите строку: ( [ ) ] 
```  
```
Строка ложна 
```  

**Требования:**  

- Использовать строку ``string`` для ввода данных.  
- Проверять ввод с помощью функции ``check()``.  
- Определять корректность последовательности с помощью функции ``checkBrackets()``.  
- Поддерживать обработку пустого ввода и недопустимых символов.  
- Игнорировать пробелы и табуляции в анализе строки.
