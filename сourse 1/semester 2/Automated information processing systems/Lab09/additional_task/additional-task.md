### Задание: Управление данными о днях рождения

**Цель:** Написать программу на языке C++, которая управляет данными о днях рождения и предоставляет различные функции для работы с этими данными.

**Описание:**

1. Программа должна выводить меню с возможными действиями:
   - Ввести данные о человеке.
   - Вывести данные о всех людях.
   - Показать именинников текущего месяца.
   - Выход из программы.
2. Программа должна запрашивать у пользователя выбор действия и выполнять соответствующие операции.
3. При вводе данных о человеке программа должна запрашивать фамилию, имя, отчество, месяц и год рождения.
4. Программа должна хранить данные о людях в векторе структур.
5. При выводе данных о всех людях программа должна отображать фамилию, имя, отчество, месяц и год рождения каждого человека.
6. При показе именинников программа должна определять текущий месяц и выводить поздравление для тех, у кого день рождения в этом месяце.

**Пример работы программы:**

```
	    Структура "День рождения"
1 - Ввести данные о человеке
2 - Вывести данные о всех людях
3 - Показать именинников
Любое другое число - Выход из программы
Выбранное действие: 1

Фамилия: Иванов
Имя: Иван
Отчество: Иванович
Месяц рождения (цифрами, где январь - 1): 5
Год рождения (цифрами): 1990

	***Данные успешно внесены***

1 - Ввести данные о человеке
2 - Вывести данные о всех людях
3 - Показать именинников
Любое другое число - Выход из программы
Выбранное действие: 2

1) Иванов Иван Иванович, 5 месяц 1990 год

1 - Ввести данные о человеке
2 - Вывести данные о всех людях
3 - Показать именинников
Любое другое число - Выход из программы
Выбранное действие: 3

Happy birthday, Иванов Иван Иванович! Теперь Вам 34
```

**Требования:**

- Использовать структуру `birthday` для хранения данных о человеке.
- Использовать вектор `vector<birthday>` для хранения списка людей.
- Использовать функции `time()` и `localtime()` для определения текущего месяца.
- Обеспечить корректный ввод и вывод данных.
- Обрабатывать некорректный ввод и выводить соответствующие сообщения.
