# 📘 Портфолио лабораторных работ по дисциплине "Основы алгоритмизации и программирования"  

Этот документ содержит описание лабораторных работ с 9 по 15, выполненных в рамках дисциплины "ОАиП". В каждой работе представлены цели, выполненные задачи, использованные технологии и полученные результаты.

## 🔹 Лабораторная работа №9: Структуры, объединения, перечисления  
**🎯 Цель:** Освоение структур данных, объединений и перечислений, их применение в практике.  

**📌 Задачи:**  
- Создание структуры "Сотрудник" для хранения персональных данных.  
- Реализация сортировки массива структур по фамилии.  
- Разработка меню для ввода, вывода, поиска, редактирования и удаления данных.  

**🛠️ Технологии:** C++, структуры, объединения, перечисления.  
**✅ Результат:** Получены практические навыки работы со структурами данных.

## 🔹 Лабораторная работа №10: Процедуры и функции  
**🎯 Цель:** Закрепление навыков использования процедур, функций и рекурсии.  

**📌 Задачи:**  
- Разработка процедуры для преобразования массива в матрицу.  
- Создание функции для перевода двоичного числа в десятичное.  
- Реализация рекурсивной функции вычисления чисел Фибоначчи.  

**🛠️ Технологии:** C++, процедуры, функции, рекурсия.  
**✅ Результат:** Освоены механизмы работы с функциями, процедурами и рекурсией.

**🎯 Цель:** Изучение динамических массивов структур и указателей на функции.  

**📌 Задачи:**

**🛠️ Технологии:** C++, динамические массивы, указатели на функции.  
**✅ Результат:** Получены знания о динамических структурах и их взаимодействии с функциями.

**🛠️ Технологии:** C++, файловый ввод/вывод.  
**✅ Результат:** Получены навыки работы с текстовыми файлами и их обработкой.
