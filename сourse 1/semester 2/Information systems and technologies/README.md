# Портфолио лабораторных работ по дисциплине "Информационные системы и технологии"

Здесь представлены мои лабораторные работы с 1 по 3, выполненные по дисциплине "ИСиТ". Каждая работа содержит описание задачи, использованные технологии и результаты.

---

## 🔹 Лабораторная работа №1: Частотные таблицы и энтропия файлов  
**🎯 Цель:** Написать программу для определения частоты появления байтов в файле и оценки его энтропии.  

**📌 Задачи:**  
- Реализация программы для подсчета частоты появления каждого байта в файле.  
- Вычисление энтропии файла и количества информации в нем.  
- Запись результатов в файл с расширением .tab.  

**🛠️ Технологии:** C++, обработка файлов.  
**✅ Результат:** Освоены методы подсчета частоты байтов и вычисления энтропии.  

---

## 🔹 Лабораторная работа №2: Построение кода сжатия информации  
**🎯 Цель:** Изучение методов сжатия информации, таких как Шеннон-Фано и Хаффмен.  

**📌 Задачи:**  
- Реализация программы для построения кодов сжатия на основе частотных таблиц.  
- Использование методов Шеннона-Фано или Хаффмена для сжатия данных.  
- Создание результирующих файлов с кодами сжатия.  

**🛠️ Технологии:** C++, методы сжатия, Шеннон-Фано, Хаффмен.  
**✅ Результат:** Изучены алгоритмы сжатия информации и получены практические навыки их реализации.  

---

## 🔹 Лабораторная работа №3: Сжатие (архивация) и восстановление (разархивация) файлов  
**🎯 Цель:** Изучить методы сжатия и восстановления файлов с использованием кодов сжатия.  

**📌 Задачи:**  
- Реализация программы для архивации и восстановления файлов.  
- Использование кодов сжатия для уменьшения размера файлов и восстановления исходных данных.  

**🛠️ Технологии:** C++, архивирование, разархивирование, файловый ввод/вывод.  
**✅ Результат:** Изучены методы сжатия и восстановления данных с помощью кодов сжатия.
