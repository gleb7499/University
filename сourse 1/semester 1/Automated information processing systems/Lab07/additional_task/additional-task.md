### Задание: Тест по основам алгоритмизации и программирования (ОАиП)

**Цель:** Написать программу на языке C++, которая реализует тест по основам алгоритмизации и программирования.

**Описание:**

1. Программа должна выводить на экран приветственное сообщение и название теста.
2. Программа должна содержать несколько вопросов с вариантами ответов.
3. Пользователь должен вводить номер выбранного ответа.
4. Программа должна проверять корректность введенного ответа и выводить соответствующее сообщение.
5. В конце теста программа должна выводить количество правильных и неправильных ответов.

**Пример работы программы:**

```
		Тест по ОАиП

		Вопрос №1
Что такое струтурное программирование?
1) Представление программы в виде иерархической структуры блоков
2) Представление программы в виде совокупности взаимодействующих объектов, каждый из которых является экземпляром определённого класса, а классы образуют иерархию наследования
3) Верны оба варианта
4) Оба варианта неверные
Ответ: 1
Верно

		Вопрос №2
Что такое ветвление?
1) Переход в другую часть программы в зависимости от значения соответствующего выражения
2) Однократное выполнение одной из двух или более операций, в зависимости от выполнения заданного условия
3) Верны оба варианта
4) Неверные оба варианта
Ответ: 3
Верно

...
```

**Требования:**

- Использовать цикл `do-while` для проверки корректности ввода.
- Использовать условные операторы `if` и `switch` для обработки ответов.
- Обеспечить корректный ввод и вывод данных.
- Программа должна выводить сообщение об ошибке при некорректном вводе.
