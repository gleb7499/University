# Лабораторные работы по ООП

## 📌 Описание
Данный раздел содержит лабораторные работы по дисциплине **"Объектно-ориентированное программирование"**. Они направлены на изучение принципов ООП и их практическое применение в языке программирования C++.

## 🔍 Список лабораторных работ

1. **Моделирование работы пункта оплаты** (`tollBooth`) – учет проезжающих машин и подсчет выручки.
2. **Операции с временными объектами** (`_time`) – перегрузка операторов для сложения временных значений.
3. **Управление объектами сотрудников** (`employee`) – работа с информацией о сотрудниках и статическими членами классов.
4. **Работа с датами** (`_date`) – обработка и вывод даты в заданном формате.
5. **Работа с угловыми координатами** (`angle`) – представление координат в градусах, минутах и направлении.
6. **Операции с дробями** (`fraction`) – арифметические операции с учетом наибольшего общего делителя.
7. **Моделирование кораблей** (`ship`) – наследование от `angle` для хранения информации о судах и их координатах.
8. **Очередь (Queue) с шаблонами** – реализация структуры данных `Queue` с поддержкой различных типов.
9. **Стек (Stack) с шаблонами** – работа с объектами разных типов с использованием `Stack`.
10. **Двусвязный список (List)** – поддержка вставки, удаления и вывода элементов.
11. **Операции с матрицами** (`Matrix`) – задание матриц и вычисление их детерминанта.
12. **Работа с денежными суммами** (`bMoney`) – операции сложения денежных значений.

## 🎯 Цель лабораторных работ
Лабораторные работы направлены на освоение:
- Основных принципов ООП: **инкапсуляции, наследования, полиморфизма**.
- Перегрузки операторов и работы со статическими членами классов.
- Использования шаблонов классов и контейнеров STL.
- Разработки структур данных, таких как **стек, очередь и двусвязный список**.

## 🚀 Запуск программ
Программы компилируются и запускаются в среде C++ (GCC, Clang, MSVC). Например:
```sh
g++ -o program Source.cpp
./program
```

## ✅ Итог
Лабораторные работы помогают закрепить теоретические знания и развить практические навыки в объектно-ориентированном программировании. Они дают возможность лучше понять ключевые концепции разработки программного обеспечения.
