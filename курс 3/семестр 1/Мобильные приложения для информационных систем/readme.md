# 📱💻 Мобильные приложения для информационных систем

## 📖 О дисциплине
Дисциплина **"Мобильные приложения для информационных систем"** изучает разработку программного обеспечения для мобильных устройств. В рамках курса студенты осваивают ключевые технологии и инструменты, используемые при создании мобильных приложений, включая проектирование интерфейсов, работу с базами данных, взаимодействие с сенсорами и мультимедийными ресурсами.

---

## 📂 Структура репозитория
Этот репозиторий содержит учебные материалы по дисциплине **"Мобильные приложения для информационных систем"**, организованные в две основные директории:

- **`Задания/`** — лабораторные работы, направленные на изучение различных аспектов разработки мобильных приложений.
- **`Курсовой проект/`** — курсовой проект, представляющий собой более сложное мобильное приложение.

---

## 🔹 Лабораторные работы
Лабораторные работы расположены в папке **`Задания/`** и охватывают ключевые аспекты разработки мобильных приложений. В ходе выполнения работ студенты знакомятся с основами Android-разработки, взаимодействием с API, обработкой жестов, созданием интерфейсов и хранением данных. Подробное описание лабораторных работ представлено в `README.md` внутри папки **`Задания/`**.

### 📌 Список лабораторных работ:
1. **Разработка первого мобильного приложения** – знакомство с Android Studio, создание интерфейсов, работа с макетами.
2. **Работа с пользовательским вводом** – формы, кнопки, обработка событий.
3. **Хранение данных** – работа с SQLite и SharedPreferences.
4. **Взаимодействие с интернетом** – сетевые запросы, работа с API.
5. **Использование мультимедиа** – работа с изображениями, аудио и видео.

Каждая лабораторная работа сопровождается инструкцией и примерами кода.

## 🎓 Курсовой проект
В папке **`Курсовой проект/`** находится курсовой проект, демонстрирующий применение знаний, полученных в ходе изучения дисциплины. Он включает разработку полноценного мобильного приложения с использованием современных технологий Android-разработки.

### 📌 Описание курсового проекта:
Курсовой проект представляет собой **мобильное приложение для учета донаций крови**. Его основная цель – автоматизация процесса учета донорства, что делает процесс удобным и интуитивным для пользователей.

### 🔹 Основные функции:
✅ Регистрация и авторизация через Firebase  
✅ Ведение учета донаций – ввод даты, типа сдачи и объема крови  
✅ Просмотр истории донаций  
✅ Редактирование и удаление записей  
✅ Работа с базой данных SQLite  
✅ Современный UI, основанный на Material Design 3  

Исходный код курсового проекта доступен в открытом доступе на GitHub: [GitHub: LifeLine](https://github.com/gleb7499/course_project_5_term/)
