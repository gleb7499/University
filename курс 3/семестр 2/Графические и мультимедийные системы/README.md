# 📸 Проект «Графические и мультимедийные системы»

Этот проект был разработан в рамках одноимённой дисциплины и представляет собой полноценное Python-приложение для обработки растровых изображений. Он демонстрирует базовые принципы работы с изображениями: от чтения и сохранения в различных форматах — до фильтрации шума и выделения контуров.

Проект построен модульно, что облегчает масштабирование и отладку. Ниже — краткий обзор архитектуры и реализованных лабораторных заданий.

---

## ⚙️ Архитектура проекта

Приложение разделено на четыре основных модуля (см. ``src``):

* **`main.py`** — точка входа. Запускает консольное меню, откуда можно выбрать нужную операцию: загрузка изображений, добавление шума, фильтрация, выделение контуров и т.д.

* **`rasterFiles.py`** — отвечает за чтение/запись изображений в форматах BMP и собственном `.LGO (FIO)`. Также здесь реализовано наложение изображений с эффектом **Color Dodge**, а ещё — функции для извлечения метаданных из заголовков файлов.

* **`filteringImages.py`** — включает реализацию добавления шума и фильтров для его подавления. Работа ведётся с импульсными помехами и крестообразными медианными фильтрами.

* **`outlineSelection.py`** — занимается выделением контуров: перевод в градации серого, применение масок (в т.ч. свёрточных), бинаризация.

---

## 🧪 Лабораторные работы и реализованные варианты

### 🔬 Лабораторная №1: *Структура растровых файлов*

**Цель**: Понять, как устроены BMP-файлы, научиться читать и сохранять изображения, а также разрабатывать собственный формат.
**Вариант 40**: Наложение изображений с помощью Color Dodge.

* Обрабатываются два BMP-файла, применяется эффект, сохраняется результат как BMP и `.LGO`.
* Чтение заголовков и попиксельные преобразования включены.
  **Файл:** `rasterFiles.py`

---

### 🧹 Лабораторная №2: *Фильтрация изображений*

**Цель**: Борьба с импульсными шумами, реализация фильтров.
**Вариант 37**:

* Генерация аддитивного шума ("соль и перец").
* Применение медианного фильтра с крестообразной маской (размер условный, не классический 5×5).
  **Примечание:** Используется стандартный медианный фильтр; взвешивание не реализовано.
  **Файл:** `filteringImages.py`

---

### 🧱 Лабораторная №3: *Выделение контуров*

**Цель**: Освоить алгоритмы нахождения границ объектов.
**Вариант 4**:

* Преобразование изображения в серый цвет.
* Применение универсальной свёрточной маски.
* Бинаризация результата.
  **Примечание:** Используемая маска не строго северо-западная, как в варианте.
  **Бонус:** Сравнительный анализ эффективности на разных стадиях обработки (исходник, шум, фильтр и их комбинации).
  **Файл:** `outlineSelection.py`

---

### 🧠 Лабораторная №4: *Работа с OpenCV (описание концепции)*

**Цель**: Применение продвинутых функций из библиотеки OpenCV.
**Реализуемые концепты (описаны, но не реализованы):**

* **Вариант 5:** Размытие через `cv2.filter2D`.
* **Вариант 8:** Детектирование краёв с помощью оператора Собеля (`cv2.Sobel`).
* **Вариант 12 (часть 1):** Сегментация с использованием `cv2.floodFill`.
* **Вариант 12 (часть 2):** Онлайн-обработка видео: захват с камеры, выделение объектов заданного цвета, отрисовка контуров, интерактив.
  **Примечание:** Эта лабораторная реализована только концептуально — без кода.

## 🚀 Как запустить

1. Установите зависимости:

```bash
pip install Pillow numpy
# Для OpenCV, если будете реализовывать ЛР4:
# pip install opencv-python
```

2. Запустите основное меню:

```bash
python main.py
```

3. Выбирайте нужную операцию в консоли — всё по инструкции.

## 📦 Используемые библиотеки

* **Pillow** — базовые операции с изображениями.
* **NumPy** — работа с массивами.
* **struct** — чтение бинарных заголовков BMP и LGO.
* **random** — генерация шума.
* **(опционально)** OpenCV — для продвинутой обработки и работы с видео.
