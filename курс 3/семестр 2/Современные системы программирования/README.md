# ☕ Современные системы программирования (ССП)

## 📘 О дисциплине

**"Современные системы программирования" (ССП)** — это практико-ориентированный курс, цель которого — освоение основных принципов и инструментов разработки программ на Java. Через серию лабораторных работ студенты получают не только теоретическую базу, но и реальные навыки программирования, включая работу с консольными утилитами, файловой системой, объектно-ориентированным проектированием и структурами данных.

---

## 📁 Структура репозитория

Материалы организованы по директориям, соответствующим номерам лабораторных работ:

* `lab_1/` — исходный код и отчёт по Лабораторной работе №1
* `lab_2/` — материалы по Лабораторной работе №2
* `lab_3/` — материалы по Лабораторной работе №3
* `lab_4/` — материалы по Лабораторной работе №4

Каждая папка содержит поддиректорию `src/` с исходными Java-файлами и, при необходимости, дополнительные скрипты и вспомогательные файлы.

---

## 🧪 Лабораторные работы

### 🔹 Лабораторная работа №1: *Параметры командной строки и базовые операции Java*

**Цель:** освоить работу с аргументами командной строки и повторить основы синтаксиса Java.
**Задачи:**

* Проверка равенства всех элементов целочисленной последовательности
* Генерация квадратной матрицы со случайными значениями
* Замена регистра символов в строке

**Вывод:** реализованы базовые утилиты на Java без использования сторонних библиотек. Получены практические навыки работы со строками, циклами, массивами и вводом из консоли.

---

### 🔹 Лабораторная работа №2: *Работа с файловой системой и консольные утилиты*

**Цель:** научиться обрабатывать текстовые файлы с помощью Java.
**Задачи:**

* Удаление повторяющихся слов из текстового файла (с сохранением первого вхождения)
* Создание утилиты `split` для разбиения файла на части по заданному количеству байт или строк, с поддержкой суффиксов в названиях файлов

**Вывод:** изучены и применены средства работы с файлами и потоками ввода-вывода. Программа завернута в `.jar`, добавлен `.bat`-файл для удобного запуска.

---

### 🔹 Лабораторная работа №3: *Классы и работа с памятью*

**Цель:** научиться создавать собственные классы и управлять данными через абстракции.
**Задачи:**

* Класс «Множество целых чисел ограниченной мощности»: поддержка операций объединения, удаления/добавления элементов, переопределение `toString()` и `equals()`
* Моделирование заполнения гибкого диска (1.44 МБ): учёт свободных и занятых блоков, запись и удаление файлов

**Вывод:** в рамках работы были реализованы собственные структуры данных и симулятор файловой системы. Получен опыт проектирования классов, управления памятью и логики хранения информации.

---

### 🔹 Лабораторная работа №4: *Объектно-ориентированное проектирование*

**Цель:** углубить знания в ООП, отработать принципы композиции, агрегации, вложенных классов.
**Задачи:**

* `Catalog` и внутренний класс `Entry`: история выдачи книг читателям
* `Page` и `Paragraph`: пример агрегации и иерархии компонентов
* Система "Вступительные экзамены": классы `Applicant`, `Faculty`, `Teacher`, `Exam` с логикой регистрации, оценивания и отбора абитуриентов

**Вывод:** получены навыки моделирования сложных сущностей, продемонстрировано использование композиции, внутреннего класса, ассоциаций и наследования. Работа приближена к реальному объектному проектированию.

---

## ✅ Итог

Этот репозиторий — не просто набор лабораторных работ, а пошаговое руководство по освоению **Java от базовых конструкций до проектирования сложных систем**. Здесь студент проходит путь от командной строки и файлов — до продвинутого объектно-ориентированного мышления.

🛠️ Проекты реализованы с нуля, что делает их отличной практикой как для новичков, так и для тех, кто хочет закрепить понимание основ Java.
