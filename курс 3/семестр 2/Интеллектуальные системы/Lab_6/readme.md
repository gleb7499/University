# 🧠 Лабораторная работа №6: Обработка текстов с помощью RNN и Conv1D

## 📌 Цель работы

Разобраться с методами представления и обработки текстов, научиться применять:

* Bag of Words;
* Встраивающие представления слов (Embedding, Word2Vec);
* Рекуррентные нейросети (LSTM, Bidirectional LSTM);
* Одномерные свёрточные сети (Conv1D).

И собрать воедино пайплайн от подготовки данных до классификации и углублённого анализа собственного текста.

## 📝 Постановка задачи

1. Загрузить и подготовить корпус текстов (20 авторов).
2. Разбить на обучающую (80%) и тестовую (20%) выборки.
3. Провести эксперименты с разными подходами:
   
   * BoW + Dense;
   * Embedding + LSTM;
   * Embedding + Conv1D;
   * Word2Vec + BiLSTM;
   * Word2Vec + Conv1D.
4. Создать собственный текст (>350 слов) и классифицировать его лучшими моделями.
5. Выполнить не менее пяти задач NLP над собственным текстом:
   
   * токенизация;
   * удаление стоп-слов;
   * лемматизация;
   * извлечение именованных сущностей;
   * построение облака слов.

## 🧩 Структура проекта

* **data/** — исходные тексты авторов и разметка выборок.
* **notebooks/** — Jupyter Notebook с экспериментациями.
* **models/** — сохранённые веса лучших моделей.
* **results/** — графики, матрицы ошибок, облако слов.

### 🔹 Подготовка данных

* Сбор 20 файлов `.txt` с произведениями разных авторов.

* Формирование train/test в отношении 80/20.
* Генерация пользовательского текста (>350 слов) с помощью ChatGPT.

### 🔹 Классификация собственного текста

| Модель               | Предсказание | Вероятность |
| -------------------- | ------------ | ----------- |
| Bag of Words + Dense | Каверин      | 94.6%       |
| Embedding + Conv1D   | Чехов        | 56.7%       |

Лидирует BoW+Dense. Причина этому - разбалансировка исходных данных, на который училась модель.

### 🔹 NLP-задачи над своим текстом

1. **Токенизация**: разделение на слова.
<br> ```['Как', 'искусственный', 'интеллект', 'влияет', 'на', 'нашу', 'жизнь', 'Ещё', 'десять', 'лет', 'назад', 'искусственный', 'интеллект', 'казался', 'чем', 'то', 'из', 'фантастики', 'Люди', 'говорили']```
2. **Удаление стоп-слов**: очистка мусорных слов.
<br> ```['искусственный', 'интеллект', 'влияет', 'нашу', 'жизнь', 'ещё', 'десять', 'лет', 'назад', 'искусственный', 'интеллект', 'казался', 'фантастики', 'люди', 'говорили', 'роботах', 'которые', 'будут', 'убирать', 'дома']```
3. **Лемматизация**: нормализация форм.
<br> ```['искусственный', 'интеллект', 'влиять', 'наш', 'жизнь', 'ещё', 'десять', 'год', 'назад', 'искусственный', 'интеллект', 'казаться', 'фантастика', 'человек', 'говорить', 'робот', 'который', 'быть', 'убирать', 'дом']```
4. **Извлечение сущностей**: ORG, PERSON, LOC.
<br> ```•	Alexa (ORG)
•	Google (ORG)
•	ИИ (ORG)
•	YouTube (ORG)
•	Netflix (ORG)```
5. **Облако слов**: визуализация частот.
