# 🧠 Лабораторная работа №8: Решение задачи коммивояжера

## 📌 Цель работы

Изучить и реализовать метод ветвей и границ (алгоритм Литтла) для точного решения задачи коммивояжера (TSP) как вручную для небольшого числа городов (4–5), так и программно для большего набора городов.

## 📝 Постановка задачи

1. Выбрать набор городов и расстояний между ними.
2. Выполнить ручное решение задачи коммивояжера для четырёх городов, продемонстрировав процедуру редукции и расчёта штрафов по методу Литтла.
3. Разработать программу для решения задачи TSP на большем числе городов (до 10) с использованием алгоритма Литтла или динамического программирования.

## 📾 Этапы выполнения

### 1. Ручное решение (метод Литтла)

* **Исходные данные**: 4 города — Брест, Орша, Слоним, Полоцк; матрица расстояний приведена в разделе отчёта.
* **Шаг 1. Редукция по строкам**: вычитание минимальных элементов строк, подсчёт суммы вычетов для lower bound.
* **Шаг 2. Редукция по столбцам**: аналогично для столбцов, обновление lower bound.
* **Шаг 3. Вычисление штрафов**: для каждого нуля находим сумму минимальных элементов строки и столбца без этого нуля, выбираем максимальный штраф.
* **Шаг 4. Ветвление**: включение/исключение перехода с наибольшим штрафом, повторение редукций и расчётов lower bound.
* **Результат ручного решения**: оптимальный маршрут для 4 городов:

  ```text
  Брест → Слоним → Полоцк → Орша → Брест
  Total distance = 1370 км
  ```
