# 🧠 Интеллектуальные системы

## 📖 О дисциплине
Дисциплина **«Интеллектуальные системы»** охватывает фундаментальные концепции и практические применения искусственного интеллекта. Курс посвящён изучению широкого спектра тем: от классических моделей представления знаний на языке **Prolog** до разработки и обучения современных **нейронных сетей** на **Python**.

В рамках этого курса были изучены методы представления знаний, теория игр, машинное обучение для задач классификации и регрессии, обработка естественного языка (NLP) и решение классических оптимизационных задач.

## 📂 Лабораторные работы

### 🔹 Лабораторная работа №1: Продукционная модель представления знаний
**🎯 Цель:** Разработать продукционную модель для системы карьерного консультанта.

**📌 Основные задачи:**
- Создать базу фактов о пользователях и вакансиях.
- Реализовать правила (продукции) для подбора вакансий и формирования рекомендаций.
- Выполнять запросы для демонстрации работы логики.

**🛠️ Технологии:** Prolog, продукционная модель.

**✅ Результат:** Создана система, способная давать карьерные советы на основе набора логических правил.

---

### 🔹 Лабораторная работа №2: Семантическая сеть представления знаний
**🎯 Цель:** Построить семантическую сеть для описания предметной области карьерного консультирования.

**📌 Основные задачи:**
- Определить основные понятия (пользователь, вакансия, навык) и связи между ними (`is_a`, `has_property`).
- Реализовать сеть в виде фактов Prolog.
- Проверить целостность модели через запросы к базе знаний.

**🛠️ Технологии:** Prolog, семантические сети.

**✅ Результат:** Разработана модель знаний, графически представляющая отношения между объектами и их свойствами.

---

### 🔹 Лабораторная работа №3: Фреймовая модель представления знаний
**🎯 Цель:** Спроектировать фреймовую модель для системы бронирования отеля.

**📌 Основные задачи:**
- Создать иерархию классов (фреймов), таких как «Пользователь», «Номер», «Бронь».
- Заполнить слоты (атрибуты) для каждого фрейма.
- Реализовать наследование свойств и процедуры-демоны.

**🛠️ Технологии:** Prolog, фреймовая модель.

**✅ Результат:** Построена структурированная база знаний, имитирующая объектно-ориентированный подход для описания сложной системы.

---

### 🔹 Лабораторная работа №4: Машинное решение игры в смешанных стратегиях
**🎯 Цель:** Реализовать симуляцию игры «Дилемма шерифа» для демонстрации принятия решений в условиях неопределённости.

**📌 Основные задачи:**
- Разработать вероятностные стратегии для двух игроков (шерифа и торговца).
- Реализовать игровую логику, где решения игроков влияют на их будущие действия.
- Провести симуляцию и проанализировать итоговые результаты.

**🛠️ Технологии:** Python, теория игр, вероятностное моделирование.

**✅ Результат:** Создана программа, симулирующая конкурентное взаимодействие агентов на основе смешанных стратегий.

---

### 🔹 Лабораторная работа №5: Распознавание рукописных цифр (MNIST)
**🎯 Цель:** Разработать и обучить нейронную сеть для классификации изображений.

**📌 Основные задачи:**
- Подготовить и нормализовать датасет MNIST.
- Спроектировать архитектуру полносвязной нейронной сети.
- Обучить модель и оценить её точность на тестовых данных и собственных изображениях.

**🛠️ Технологии:** Python, TensorFlow, Keras, нейронные сети.

**✅ Результат:** Получена модель, способная с высокой точностью (98%) распознавать рукописные цифры.

---

### 🔹 Лабораторная работа №6: Обработка текстов с помощью RNN и Conv1D
**🎯 Цель:** Изучить и сравнить различные подходы к классификации текстов.

**📌 Основные задачи:**
- Применить модели `Bag of Words`, `Embedding`, `LSTM` и `Conv1D` для определения автора текста.
- Использовать предобученные векторы `Word2Vec`.
- Выполнить комплексный NLP-анализ текста: токенизацию, лемматизацию, извлечение сущностей (NER).

**🛠️ Технологии:** Python, TensorFlow, Keras, NLP, RNN, LSTM, Conv1D.

**✅ Результат:** Проведён сравнительный анализ моделей текстовой классификации и реализован полный пайплайн обработки естественного языка.

---

### 🔹 Лабораторная работа №7: Нейронные сети для решения задачи регрессии
**🎯 Цель:** Применить нейронные сети для предсказания непрерывной величины.

**📌 Основные задачи:**
- Подготовить табличный датасет Auto MPG.
- Стандартизировать признаки для корректной работы модели.
- Обучить нейронную сеть для предсказания расхода топлива и оценить её ошибки (MAE, MSE).

**🛠️ Технологии:** Python, TensorFlow, Keras, Scikit-learn, регрессия.

**✅ Результат:** Разработана модель, способная предсказывать числовые значения, и проведена визуальная оценка её качества.

---

### 🔹 Лабораторная работа №8: Решение задачи коммивояжера
**🎯 Цель:** Изучить и реализовать точный метод решения задачи комбинаторной оптимизации.

**📌 Основные задачи:**
- Изучить метод ветвей и границ (алгоритм Литтла).
- Выполнить ручной расчёт оптимального маршрута для 4 городов.
- Разработать программную реализацию для поиска маршрута в графе из 10 городов.

**🛠️ Технологии:** Python, алгоритмы, комбинаторная оптимизация, метод ветвей и границ.

**✅ Результат:** Реализован алгоритм для нахождения оптимального решения классической NP-трудной задачи.

---

## 📜 Итог
В ходе выполнения лабораторных работ был освоен широкий спектр тем из области искусственного интеллекта. Получены практические навыки в следующих областях:
- **Представление знаний:** Использование **Prolog** для создания продукционных, семантических и фреймовых моделей.
- **Машинное обучение:** Применение **Python** и **TensorFlow/Keras** для решения задач классификации (изображений, текстов) и регрессии.
- **Обработка естественного языка (NLP):** Реализация пайплайнов от предобработки текста до его анализа с помощью рекуррентных и свёрточных сетей.
- **Алгоритмы и оптимизация:** Решение задач из теории игр и комбинаторной оптимизации (TSP).

Этот курс позволил сформировать комплексное понимание современных интеллектуальных систем, начиная от теоретических основ и заканчивая их практической реализацией для решения реальных задач.
