# 🌐 Веб-технологии

## 📖 О дисциплине
Дисциплина **"Веб-технологии"** посвящена изучению основ веб-разработки, включая работу с **HTML, CSS, JavaScript** и современными **фреймворками**. В рамках курса студенты осваивают создание пользовательских интерфейсов, работу с UI-библиотеками, применение клиентского JavaScript и разработку интерактивных веб-приложений.

Исходные коды всех лабораторных работ находятся в репозитории:  
🔗 [GitHub-репозиторий](https://github.com/gleb7499/web-technologies/tree/main)

---

## 📂 Лабораторные работы

### 🔹 Лабораторная работа №1: Создание интерфейса веб-приложений
**🎯 Цель:** Разработать веб-форму с использованием **HTML5** и **CSS3**.

**📌 Основные задачи:**
- Настроить локальный веб-сервер.
- Сверстать форму с полями ввода, выпадающими списками и кнопками управления.
- Реализовать валидацию формы средствами HTML5 и CSS3.
- Использовать регулярные выражения для проверки введенных данных.

**🛠️ Технологии:** HTML5, CSS3.

**✅ Результат:** Создан статический интерфейс веб-формы с базовой валидацией и удобным пользовательским взаимодействием.

---

### 🔹 Лабораторная работа №2: Интерфейс с использованием UI-фреймворка
**🎯 Цель:** Разработать веб-форму с помощью **Bootstrap**.

**📌 Основные задачи:**
- Использовать **CSS-препроцессоры** (LESS, SCSS, Stylus).
- Подключиться через **Telnet** к веб-сайту и изучить HTTP-заголовки.
- Сгенерировать **SSL-сертификат** для localhost.
- Разработать веб-форму с применением компонентов Bootstrap.

**🛠️ Технологии:** Bootstrap, CSS-препроцессоры, Telnet, SSL.

**✅ Результат:** Создан адаптивный веб-интерфейс с удобной навигацией и продвинутыми UI-компонентами.

### 🔹 Лабораторная работа №4: Использование JS-фреймворка (Vue.js)
**🎯 Цель:** Изучить работу **Vue.js** и применить его в разработке веб-приложений.

**📌 Основные задачи:**
- Разработать приложение с несколькими взаимосвязанными веб-формами.
- Использовать **Vue.js** для управления состоянием компонентов.
- Реализовать интерактивные элементы и связи между формами.

**🛠️ Технологии:** Vue.js, JavaScript, компонентный подход.

**✅ Результат:** Разработано интерактивное веб-приложение с динамическим обновлением данных.
