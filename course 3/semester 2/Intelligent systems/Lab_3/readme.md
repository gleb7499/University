# 📚 Лабораторная работа №3: Фреймовая модель представления знаний

## 🔎 Описание

Лабораторная работа посвящена разработке **фреймовой модели** для **Системы бронирования отеля**.
Модель описывает иерархию классов, атрибуты и методы, а также выполняет диагностику и рекомендации для пользователей.

### 🎯 Цель
- Построение фреймовой модели для предметной области.
- Включение не менее 12 понятий и использование не менее 3 типов отношений.
- Реализация модели в **Prolog**.
- Выполнение запросов для анализа данных и проверки модели.

### 📄 Файлы
- `lab_3.pl` – исходный код на Prolog с фактами, правилами и логикой фреймовой модели.
- `Иерархия-классов.png` – графическое представление иерархии классов.
- `README.md` – описание проекта и инструкция по запуску.

## 🛠️ Инструкция по запуску

### Требования
- Установленный интерпретатор SWI-Prolog.
- Файл `lab_3.pl` в рабочем каталоге.

### Шаги для запуска
1. **Открыть SWI-Prolog:**
   ```bash
   swipl
   ```
2. **Загрузить файл:**
   ```prolog
   ?- [lab_3].
   ```
3. **Выполнить запросы:**
   ```prolog
   ?- show_user_info(ivan).
   ?- suitable_vacancy(maria, Vacancy).
   ?- recommendation_for(alexey, Recommendation).
   ```
