# Курсовая работа: BookMaster 📖💻

## 📌 О проекте
**BookMaster** – это приложение для управления библиотекой, разработанное с использованием **Qt**. Оно позволяет пользователям добавлять, редактировать и удалять информацию о книгах, а также просматривать доступные записи.

## 🎯 Основная цель проекта
Проект направлен на создание удобного и интуитивного интерфейса для работы с каталогом книг. Он помогает автоматизировать учет литературы и обеспечивает удобный способ организации библиотеки.

## 🔍 Основные возможности
- Просмотр списка книг 📚
- Добавление новых записей 📝
- Редактирование существующих данных ✏️
- Удаление книг из базы ❌
- Удобный графический интерфейс 🖥️

## 🛠️ Используемые технологии
- **Qt 4.x** – кроссплатформенный фреймворк для создания GUI-приложений.
- **QtWidgets, QtGui, QtCore** – основные библиотеки для работы с интерфейсом и обработкой данных.

## ✅ Итог
Курсовая работа **BookMaster** демонстрирует применение объектно-ориентированного программирования и разработку GUI-приложений с использованием **Qt**. Проект предназначен для управления библиотечными записями и может быть расширен дополнительными функциями в будущем.
