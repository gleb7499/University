# Курсовая работа: Система сбора данных с площадок интернет-торговли 🛒💻

## 📌 О проекте
Данный проект представляет собой программу для парсинга электронно-коммерческих сайтов. Он автоматизирует сбор данных о продуктах и ценах, облегчая анализ информации. В качестве источника данных используется сайт [shop.mts.by](https://shop.mts.by).

## 🎯 Основная цель проекта
Проект направлен на автоматизацию процесса сбора данных с интернет-магазинов для их дальнейшего анализа и обработки. Это позволяет мониторить изменения цен и ассортимента товаров без необходимости ручного сбора информации.

## 🔍 Основные возможности
- Автоматизированный парсинг товаров с сайта 📊
- Сохранение данных в базу данных SQLite 🗄️
- Графический интерфейс для удобного взаимодействия с пользователем 🖥️
- Экспорт результатов в файлы CSV для дальнейшего анализа 📂

## 🛠️ Используемые технологии
- **Язык программирования**: Python 🐍
- **Фреймворк GUI**: CustomTkinter
- **Работа с базами данных**: SQLite
- **Парсинг данных**: BeautifulSoup, Requests, Aiohttp
- **Автоматизация браузера**: Selenium WebDriver
- **Тестирование**: PyTest

## 🚀 Запуск проекта
1. Клонируйте репозиторий:
   ```sh
   git clone https://github.com/gleb7499/course_project_4_term.git
   ```
2. Перейдите в директорию проекта:
   ```sh
   cd tppo
   ```
3. Установите необходимые зависимости:
   ```sh
   pip install -r requirements.txt
   ```
4. Запустите программу:
   ```sh
   python app/algorithms/UI.py
   ```

## ✅ Итог
Курсовая работа **"Система сбора данных с площадок интернет-торговли"** демонстрирует использование методов парсинга и автоматизации веб-доступа. Проект помогает понять принципы работы с веб-данными и их обработкой, а также развить навыки в области программирования и тестирования.
