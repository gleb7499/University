# Технологии проектирования программного обеспечения (ТППО)

## 📖 О дисциплине
Дисциплина "Технологии проектирования программного обеспечения" (ТППО) изучает методы и подходы к разработке программных систем, включая анализ требований, проектирование архитектуры и реализацию программных решений. В рамках курса студенты выполняют лабораторные работы и курсовой проект, что позволяет закрепить теоретические знания на практике.

---

## 📂 Структура репозитория
Этот репозиторий содержит материалы по дисциплине **ТППО**, организованные в две основные директории:

- **`Tasks/`** — содержит лабораторные работы, направленные на изучение различных технологий проектирования ПО.
- **`Course paper/`** — содержит курсовой проект, который представляет собой более сложное программное приложение.

---

## 🔹 Лабораторные работы
Лабораторные работы находятся в папке **`Tasks/`** и охватывают различные аспекты проектирования программного обеспечения. Они включают в себя:
- Основы Python и разработку простых программ.
- Работу с базами данных с использованием SQLite.
- Создание графических интерфейсов с Tkinter.
- Парсинг веб-страниц с использованием BeautifulSoup и Requests.
- Автоматизацию работы в браузере с Selenium WebDriver.
- Тестирование программного обеспечения с PyTest.

Полное описание лабораторных работ доступно в `README.md` внутри папки **`Tasks/`**.

---

## 📌 Курсовой проект
В папке **`Course paper/`** расположен курсовой проект **"Система сбора данных с площадок интернет-торговли"**. Проект предназначен для автоматизированного парсинга данных с интернет-магазинов, в частности с [shop.mts.by](https://shop.mts.by), и их последующего анализа.

### 🔍 Основные возможности проекта:
- Автоматический сбор данных о товарах и ценах.
- Сохранение информации в базу данных SQLite.
- Экспорт результатов в формат CSV.
- Удобный графический интерфейс для управления процессом сбора данных.

Более подробная информация представлена в `README.md` внутри папки **`Course paper/`**.

---

## 📜 Итог
Данный репозиторий служит хранилищем для учебных материалов по **ТППО**, включая лабораторные работы и курсовой проект. Он помогает студентам освоить современные технологии проектирования и разработки программного обеспечения, включая автоматизацию процессов, тестирование и работу с данными.
