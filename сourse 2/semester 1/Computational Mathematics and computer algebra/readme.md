# Решение алгебраических и трансцендентных уравнений 📊🔢

## 📌 Описание
Данный раздел содержит реализации различных численных методов решения алгебраических и трансцендентных уравнений. В папке **`theory/`** представлена теоретическая часть, а в **`solution/`** находятся исходные коды алгоритмов.

## 🔍 Реализованные методы

1. **Метод половинного деления (бисекции)** – нахождение корня уравнения путем деления интервала пополам до достижения заданной точности.
2. **Метод итераций** – последовательное уточнение корня через подстановку его приближенного значения в функцию итераций.
3. **Метод хорд (метод пропорциональных частей)** – использование линейной аппроксимации функции для нахождения корня.
4. **Метод Ньютона (метод касательных)** – основан на использовании производной функции для нахождения корня.
5. **Комбинированный метод** – сочетает метод Ньютона и метод хорд для ускоренной сходимости.

## 🛠️ Используемые технологии
- **Язык программирования**: Java ☕
- **Работа с математическими функциями** (Math API)
- **Поток управления** (циклы, ветвления)
- **Обработка пользовательского ввода** (Scanner)

## 🚀 Запуск программы
1. Перейдите в папку `solution/`
2. Скомпилируйте программу:
   ```sh
   javac Main.java
   ```
3. Запустите выполнение:
   ```sh
   java Main
   ```
