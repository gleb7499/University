# Объектно-ориентированное программирование (ООП) 🚀📚

## 📖 О дисциплине
Дисциплина "Объектно-ориентированное программирование" (ООП) охватывает ключевые концепции программирования, включая инкапсуляцию, наследование, полиморфизм и абстракцию. В ходе обучения студенты выполняют лабораторные работы и курсовой проект, что способствует закреплению теоретических знаний и развитию практических навыков. 💡💻

---

## 📂 Структура репозитория
Этот репозиторий содержит материалы по ООП, организованные в две основные директории:

- **`Tasks/`** — содержит лабораторные работы, каждая из которых демонстрирует применение принципов ООП в различных задачах. 🏗️
- **`Course paper/`** — включает в себя курсовой проект, представляющий собой более сложное программное приложение. 🎓

---

## 🧪 Лабораторные работы
Лабораторные работы расположены в папке **`Tasks/`** и направлены на изучение и применение принципов ООП. Среди представленных тем:

1. **Моделирование работы пункта оплаты** (`tollBooth`) – учет проезжающих машин и подсчет выручки. 🚗💰
2. **Операции с временными объектами** (`_time`) – перегрузка операторов для сложения временных значений. ⏳
3. **Управление объектами сотрудников** (`employee`) – работа с информацией о сотрудниках и статическими членами классов. 👨‍💼
4. **Работа с датами** (`_date`) – обработка и вывод даты в заданном формате. 📆
5. **Работа с угловыми координатами** (`angle`) – представление координат в градусах, минутах и направлении. 🧭
6. **Операции с дробями** (`fraction`) – арифметические операции с учетом наибольшего общего делителя. ➗
7. **Моделирование кораблей** (`ship`) – наследование от `angle` для хранения информации о судах и их координатах. 🚢
8. **Очередь (Queue) с шаблонами** – реализация структуры данных `Queue` с поддержкой различных типов. 🎟️
9. **Стек (Stack) с шаблонами** – работа с объектами разных типов с использованием `Stack`. 📚
10. **Двусвязный список (List)** – поддержка вставки, удаления и вывода элементов. 🔗
11. **Операции с матрицами** (`Matrix`) – задание матриц и вычисление их детерминанта. 📊
12. **Работа с денежными суммами** (`bMoney`) – операции сложения денежных значений. 💵

## 📘 Курсовой проект: BookMaster
Курсовой проект, расположенный в папке **`Course paper/`**, представляет собой приложение **BookMaster** для управления книгами, реализованное с использованием Qt.

### 🔹 Основные возможности:
- Просмотр всех книг 📖
- Добавление, редактирование и удаление книг ✏️
- Интуитивно понятный графический интерфейс на Qt 🖥️

### 🛠️ Технологический стек:
- **Qt 4.x**
- **QtWidgets, QtGui, QtCore**

### 🚀 Запуск проекта:
Для установки и запуска выполните:
```sh
git clone https://github.com/gleb7499/course_project_3_term.git
```
Далее откройте файл `BookMaster.pro` в **Qt Creator**, соберите и запустите проект.
